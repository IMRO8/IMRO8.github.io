# Rohith Papani Portfolio

A responsive static portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy on GitHub Pages

1. Push the contents of this folder to the root of the `IMRO8/portfolio` repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Main files

- `index.html`: portfolio content and structure
- `styles.css`: visual design and responsive layout
- `script.js`: mobile navigation and scroll reveals
- `assets/Rohith_Papani_Resume.pdf`: downloadable résumé
